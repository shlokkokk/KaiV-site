# KAI-VIDHYA Website Interaction Design

## Page 1: Home
**Hero Section Interactions:**
- Animated background with subtle academic-themed particles using p5.js
- Typewriter effect for main headline using Typed.js
- Call-to-action buttons with smooth hover animations and click transitions
- Scroll indicator with bounce animation

**Founders Section:**
- Image placeholders with Ken Burns zoom effect on hover
- Smooth fade-in animation on scroll

**Programs Section:**
- Interactive cards with 3D tilt effect on hover
- Smooth color transitions and shadow effects
- "Learn More" buttons with slide animations

**Results Carousel:**
- Auto-scrolling horizontal carousel using Splide.js
- Pause on hover functionality
- Click to navigate to Results page

**Testimonials:**
- Auto-rotating testimonial cards with fade transitions
- Manual navigation dots at bottom
- Smooth slide animations
