# KaiV-site

A professional, multi-page website built for a real client and deployed on Vercel.  
This project focuses on clean UI, structured front-end development, and real-world deployment workflow.

## Live Demo
[https://kai-v-site.vercel.app](https://kai-v-site.vercel.app/)

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Vercel

## Features
- Responsive multi-page layout
- Dark mode interface
- Organized asset and folder structure
- Production deployment on Vercel

## Project Structure
portal/        Student portal (under development)  
resources/     Shared assets and resources  
index.html     Main landing page  
main.js        Core JavaScript logic  

## Status
The student portal section is currently under development.  
Core website pages are complete and deployed.

## Purpose
This project was built to practice real-world front-end development, deployment, and project structuring using modern workflows.
